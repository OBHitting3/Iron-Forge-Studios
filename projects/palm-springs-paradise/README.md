# Palm Springs Paradise — Steal the Oasis

A Roblox game where players collect eggs, build desert oases, and heist each other. Set in Palm Springs, California with a mid-century modern look.

**What's in here:**
- 36 Luau (Roblox) game files
- 8 server services (economy, heists, eggs, plots, leaderboards, monetization, trading, world)
- 6 client controllers (data, eggs, heists, plots, trading, UI)
- Shared data modules (furniture, icons, constants)
- Anti-cheating protection, rate limiting, full money system

**Status:** Prototype complete. Needs art, sound effects, and testing with real players.
